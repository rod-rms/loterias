# LotoAtlas — Iconografia e Imagem

## Iconografia

Estilo:

- traço simples;
- geométrico;
- cantos arredondados;
- sem ilustrações de cassino;
- sem excesso de brilho.

Categorias visuais:

- Estratégias: barras, rede, nós;
- Carteiras: cartões/camadas;
- Análise: lupa/gráfico;
- Conferência: check/shield;
- Histórico: relógio/calendar;
- Sorte: trevo, sempre como elemento secundário.

## Fotografia

A marca pode funcionar majoritariamente sem fotografia.

Quando houver pessoas:

- adultos reais;
- contexto cotidiano;
- smartphone/notebook;
- expressão tranquila e concentrada;
- evitar euforia exagerada, chuva de dinheiro, champanhe ou “ganhador”.

## Ilustração

Preferir:

- mapas de pontos;
- redes;
- grids de dezenas;
- cartões de carteira;
- dados abstratos;
- elementos de navegação/atlas.

Evitar:

- roleta;
- caça-níquel;
- fichas de cassino;
- notas voando;
- sacos de dinheiro;
- cofres;
- trevos gigantes como único código visual.
